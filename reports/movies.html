What is this?

I've been logging every film I watch on Letterboxd and writing a short review for each one. After a few years of that, I had enough data to do something interesting with it — so I built a Python pipeline that pulls my exports, runs analysis across rating patterns, genres, directors, and release years, and trains a machine learning model on my own reviews to see whether my writing can actually predict how much I liked a film.

The data covers rated films and written reviews. Genre, director, and actor metadata is pulled from the TMDB API. The ML section uses TF-IDF text features combined with VADER sentiment scores to train a Ridge Regression and a 3-class classifier. All analysis is done locally — only the output JSON files are pushed to this page.

Can My Words Predict My Rating?

I trained two models on my reviews: a Ridge Regression to predict the exact star rating, and a 3-class Logistic Regression to classify each review as Meh (≤2.5★), Solid (3.0–3.5★), or Great (≥4.0★). Features include TF-IDF text vectors combined with VADER sentiment scores. Ridge Regression was chosen over standard linear regression to avoid overfitting in the high-dimensional TF-IDF feature space.
