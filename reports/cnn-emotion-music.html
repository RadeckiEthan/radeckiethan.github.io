Course Project

Emotion to Music Recommender
Using CNNs and OpenCV

Group Project Syracuse University Arya Patil, Caden Lippie, Ethan Radecki Complete

This project integrates facial emotion recognition with Spotify audio features to generate dynamic, emotion-aware music recommendations by analyzing a user's facial expression through a webcam and mapping the detected emotion through a CNN to a valence score range. The system recommends songs that better match the user's mood in real time, delivering more personalized and context-aware music suggestions.

Python TensorFlow / Keras CNN OpenCV FER-2013 Spotify API

Project Overview

Addressing the Gap in Real-Time Contextual Understanding

Current music recommendation systems rely heavily on users' historical listening patterns and collaborative filtering methods. While effective, these approaches lack real-time contextual understanding, particularly emotional feedback. To address this gap, this project integrates facial emotion recognition (FER) with Spotify audio features to generate dynamic, emotion-aware music recommendations.

The focus is on the use of convolutional neural networks to classify images of faces into seven different emotions. This classification task requires a convolutional neural network architecture to be designed and trained on the FER 2013 dataset. Overall, the model was estimated to be able to predict the correct emotion 60-70% of the time and thus be able to recommend a song in the accurate emotional valence.

Data Exploration

FER-2013 Dataset

The data used for this project is the FER-2013 dataset from Kaggle. This data contains a total of 35,887 48x48 pixel grayscale images of faces, organized in seven folders labeled by emotion and split into training and testing folders, with 7,178 images in the test folder and 28,709 in the train folder.

The data is a little unbalanced, with happy, neutral, and sad having more images than emotions like disgust. The disproportional amount of images labeled as disgust means the model might struggle to predict disgust relative to the other emotions. Additionally, it would be expected to see happiness predicted correctly more successfully since it encompasses 25% of the data. The images are centered on faces and are similarly zoomed in, which should allow the model to focus more on facial features and less on the environment.

Figure 1. Label distribution across the seven emotion classes in the FER-2013 dataset. Happy dominates at 25.05%, while disgust represents only 1.52% of all images.

Methods

Model Architecture and System Pipeline

The model architecture for this project is a 4-block convolutional neural network designed to classify images into 7 classes. The input layer is a 48x48x1 dimension image, meaning the image is square, 48 pixels wide and tall, and grayscale with one channel. The number of filters increases with each block (32, 64, 128, 256), with each filter learning to detect different features. The first Conv2D layers detect simpler features like edges, while the deeper layers detect more complex features.

Blocks 1-3
Two Conv2D + BatchNorm layers each

Each block ends with a max pooling layer and 25% dropout. Batch normalization smooths activations by centering them around zero. Max pooling downsamples feature maps by taking the maximum value in each 2x2 window to prevent overfitting and reduce computation.

Block 4
Single Conv2D + BatchNorm + MaxPooling

256 filters at 3x3 kernel size. ReLU activation functions introduce non-linearity across all Conv2D layers. Zero padding ensures spatial dimensions stay consistent and allows filters to learn features closer to the edges of images.

Dense Layers
Flatten then two fully connected layers

The flatten layer converts 3D feature maps into a 1D vector. The first dense layer has 256 units with ReLU activation and 50% dropout. The final dense layer outputs a probability distribution across the seven classes using softmax activation.

OpenCV Pipeline
Real-time webcam emotion detection

A single frame is captured following a five-second delay. A Haar Cascade classifier detects frontal faces, which are then resized, converted to grayscale, and preprocessed into 48x48 pixel format for input into the pre-trained model.

Figure 2. CNN architecture diagram. Four convolutional blocks with increasing filter counts (32, 64, 128, 256) feed into a flatten layer and two dense layers for 7-class emotion prediction.

Valence Mapping

The music recommendation aspect uses a valence-based mapping system. Emotions are classified based on valence intervals: Happy (0.70-1.00), Surprise (0.60-0.90), Neutral (0.45-0.65), Fear (0.10-0.30), Sad (0.00-0.25), Angry (0.05-0.25), and Disgust (0.10-0.30). The Spotify dataset is then filtered to songs within the associated range and the song title, artist, and valence score are output to the user.

The full system pipeline from webcam capture to song recommendation follows six steps:

1
Webcam Capture

The program captures a frame from the user's webcam after a brief initialization period.

2
Face Detection

The face is detected using a Haar Cascade, cropped, converted to grayscale, resized to 48x48 pixels, and normalized for the model.

3
Emotion Classification

The preprocessed image is fed into the CNN trained on FER-2013, predicting one of seven emotions: Angry, Disgust, Fear, Happy, Sad, Surprise, or Neutral.

4
Emotion-to-Valence Mapping

Each emotion is mapped to a valence range (0-1) representing positive or negative musical mood.

5
Song Filtering

Songs from the Spotify dataset are filtered to match the valence range of the predicted emotion.

6
Recommendation

One song is randomly selected from the filtered list and presented to the user with title, artist, and valence score.

Results

Emotion-by-Emotion Accuracy and Model Performance

The results show that certain emotions are better classified than others. The most accurately identified emotions were sad and happy, with approximately 80% of tested trials being accurate. Emotions such as anger, neutrality, and surprise showed relatively low to moderate accuracy. Disgust and fear were identified the least, both attaining an accuracy rate of 4%.

Model Behavior

The model was able to continue training to a limit of 40 epochs, however after approximately 14-16 the model stalls in terms of validation accuracy, thus not making any reasonable progress and increasing chances for potential overfitting. The final model validation accuracy indicates the model had an overall 46-50% accuracy when trained on the dataset, which is significantly better than leaving it to random chance at 14.3%.

Problems Encountered

Overfitting, Nuanced Emotion Detection, and Dataset Bias

Overall, the model encountered problems with overfitting, nuanced emotion detection, and emotion detection across different ethnicities. Overfitting was present throughout the development of the model and different numbers of convolutional blocks were tested for the optimum rates of validation accuracy, validation loss, and training accuracy. When initially running the model, the validation accuracy was approximately 0.23, with values of validation loss as high as 3.75. The initial 3-block model was then altered to 4 blocks to try and capture more nuanced emotions such as anger, neutral, and surprise.

Certain emotions were not as likely to be classified as others, specifically disgust, fear, and surprise. This makes sense as these emotions have similarities to emotions such as sad and anger, which explains the confusion matrix data where these three emotions were often classified as sad (disgust: 12, fear: 13, surprise: 10). While testing the model in real time, the model could not distinguish emotions unless they were very exaggerated, which is not ideal as in reality most people would be displaying emotions on a much less exaggerated scale.

This phenomenon is also analogous to the ethnicities presented in the dataset. The fact that the images are black and white makes it harder to distinguish certain features in ethnicities with darker skin complexion. In the future a larger and more inclusive dataset of ethnicities and subtle emotions should be utilized.

Evaluation of Goals

Goals Met, with Room for Improvement

Overall, the goals of this project were met. The project results did perform suboptimally when taking into context the initial predictions for the model, as a lot of the more nuanced expressions were often not classified correctly. However, the project allowed for a more successful recognition of emotion and music recommendation in a live feed than if it were left to random chance, with approximately 47-50% validation accuracy and 37% on live trials versus 14.3% for random chance.

The results could likely be optimized by utilizing a pre-existing model designed for facial recognition such as VGG-Face, ResNet50, or MobileNet-V3. Future work could include adding a reinforcement learning model in which genre could be selected more thoroughly through a feedback mechanism of the individual indicating whether they like the song genre or not.

Core Finding

The 4-block CNN trained on FER-2013 achieved 46-50% validation accuracy and 37.1% accuracy on live trials, significantly outperforming the 14.3% random chance baseline across 7 emotion classes. The system successfully integrated emotion recognition with Spotify valence mapping to deliver real-time, mood-aware music recommendations, with happy and sad emerging as the strongest performing classes at approximately 80% accuracy each.
